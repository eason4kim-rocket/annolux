## 2. 他真正在教的，不是狭义 SEO

市面上的 SEO 他叫「狭义」：会写博客、会发外链就算会了。他教的是一条生意链：

1. 站长和搜索引擎互补：谷歌需要有人满足用户搜索，你需要免费流量。
2. 先挖关键词，理解词背后的需求。
3. 做一个网站去满足这个需求（优先工具，不是文章）。
4. 写好落地页，做好 On-Page，拿到曝光和点击。
5. 用内链把多个页面连成站，再做多语言。
6. 持续发外链、持续加内页，权重和排名一起涨。
7. 接 Adsense，或接支付做订阅，进入收租。

时间分配：

> **挖需求 40% : 写代码 20% : 宣传推广 40%**  
> 有了 AI 之后，开发可以压到 10% 甚至 5%，多出来的时间砸在推广上。

对新人四个字：**听话照做**。第一个站的目标不是赚钱，是走通「上线 + 目标词进谷歌前 10」。

## 3. 三句心法

2024-06-20 原话：

> **分门别类罗列**  
> **举全站之力优化**  
> **一个关键词一个页面**

2025-03-08 十句压缩版：

> 干 → 去做 → 多上站 → 勤加外链 → 多做工具页 → 跟时间交朋友 → 高竞争度也不怕 → 做个好人做个好站 → 做好用户体验很重要 → 站在谷歌角度考虑问题

| 心法 | 实际意思 |
|---|---|
| 分门别类罗列 | 先把用户会搜的说法收全、按意图分组；页面上把这个需求的所有子问题一块列出来 |
| 举全站之力 | 不要用大站一个内页去打一个词。专门为这个词做站，首页 + 多个内页从不同角度讲透 |
| 一个关键词一个页面 | 一个**意图组**一个 URL。同义词合在一页，不同需求拆开。早期甚至可以「一个词一个域名」 |

后来他写得更精确：**一个关键词组一个页面**。不要把 `ai image` 和 `ai images` 拆成两个薄页。

## 4. 全流程

### 4.1 先收词，再想网站结构

顺序不能反。先买域名、先画导航、再问「优化什么词」——这是他点名最多的新手错误。

收词入口（多入口，不要只信一个工具）：

- 谷歌下拉、相关搜索（主词 + 空格 + 字母，换同义说法）
- Google Ads 关键词规划师（最终排序尽量回到谷歌自己的量）
- Google Trends（相对热度、地区；加双引号对比哪种说法更常用）
- Ahrefs / Semrush / Similarweb（从竞品反查）
- YouTube / TikTok / Pinterest 搜索下拉
- **X 比 Trends 更快**：新东西先在社交爆 → 才有人去谷歌搜 → Trends 才冒头。用 X 高级搜索盯「近 24 小时、点赞破千、带外链」，当天反查、当天上落地页

词表字段：

关键词｜搜索量｜意图｜页面类型（首页/栏目/工具/文章）｜优先级｜备注（竞争、要不要做功能）

结构原则：

- **首页**：解释总需求 + 往下导
- **栏目页**：分门别类
- **工具页**：满足一个明确操作需求
- **文章页**：补说明，不能替代工具

用户搜的是「生成、转换、修复、下载、计算、检查」，就要打开就能用，别只给一篇博客。

### 4.2 怎么判断这个词值不值得做

**第一个站（练手）**

- Ahrefs KD < 10，所需外链站点数也 < 10
- 别看搜索量，一个月 100 次也可以
- 目标：上线 + 目标词进前 10

**新词（他最爱的红利）**

- 社交媒体刚爆、工具库里还查不到或数据是错的
- 用已知搜索量的词在 Trends 里对比，反推新词量级
- 新词可以今天上线、明天有流量
- 域名优先：不带减号 `.com` → 带减号 `.com` → `.net` / `.org`
- 用词本身注册域名

**KGR（他工具箱里做成了计算器）**

- `KGR = intitle结果数 ÷ 月搜索量`
- KGR < 0.25：供给远小于需求，新站不靠外链也常能进前 50
- **EKGR**：把 KD 折进去，避免「对手少但全是硬茬」
- **KDROI**：按外链阶梯成本估算投入回报，覆盖不了外链成本的词直接放弃
- 新站冷启动：挑 KGR < 0.25、月搜 20–250 的长尾，用一批小词滚出初始权重

**老词 / 有竞争的词**

- 别幻想上线几个月什么都不做就能排上去
- 看 SERP：前十都是首页 = 竞争大；很多是内页 = 值得做，举全站之力有机会挤掉内页
- 谷歌会先给一点点曝光测试你接不接得住
- 先发优势会衰减，要用停留时间、人均浏览页、外链把位置钉住

**不要做的词**

- 只为注水的 `Youtube Downloader` 这类：流量好看、用户不是你的人
- 搜索量很大但你提供不了更好功能/内容的词，第一批别硬刚

### 4.3 页面怎么做（TDH）

他把老派 TDK（Title / Description / Keywords）改成 **TDH**：

- Keywords 标签已被滥用，谷歌不信了
- Title、Description、Headings 才是骨架

规矩：

- 每个页面 Title 必须描述当前页，禁止全站写成网站名
- 不要所有页面 TD 相同，不要不写
- H1 = 页面主题，H2/H3 按子需求分层
- 工具页也要有足够文字，否则谷歌不知道这页在干什么
- 图片写 Alt
- Canonical 很重要，写错伤害很大
- **服务端渲染**，不要纯前端渲染
- 多语言不要用 JS 切换；页面之间必须是真正的 `<a>` 链接
- 把这个词相关的子需求在一页里分门别类列全（Kayak `car rental nyc` 那种），不是堆字数

### 4.4 整站组织：15 条上站清单

2023-11 总结群友「30 天 10 万点击 / 两周日 UV 1 万」：

1. 判断是不是新词
2. Semrush 查新词经常没量或是错的
3. 用已知词对比算出新词量
4. 用新词注册域名
5. 用页面内容解释这个词，先设计内容结构
6. 能在线试用，拉长停留
7. 内页不能少，举全站之力解释这个词
8. 内链不能少，给每个页传权重
9. 多语言不能少
10. 提交 GSC
11. Bing、Yandex 也别忽略
12. 外链不能少：加速收录 + 提升排名
13. 流量统计不能少
14. 有统计有助于 Adsense 过审
15. 日 UV > 500，最好 > 1000 再申请 Adsense

他自己的一个新站：只做 4 个页面，核心功能放首页，另外 3 页辅助；然后几个月天天发外链，GSC 曲线一直往上走。

### 4.5 外链

他反复说：没外链不行。

- 抄作业：看到任何站，下意识去看它的外链从哪来，找出你也能发的，去发
- 新站想加快收录：发到谷歌爬虫常去的地方（他提过 V2EX）
- 真金白银买：他有个新站砸了几万块买外链
- 买来的那个 2 万刀的站，外链投入约 3000 刀
- 2026-03 演示过自动发外链浏览器插件
- 别迷信第三方 DR/DA。谷歌自己的权重 ≠ Ahrefs DR

### 4.6 排名靠什么接住流量

站内和外链做完之后，最有效的加分是用户行为：

- 停留时间长
- 跳出率低
- 人均打开页面多

手段：

- 不登录就能试用，不要一上来登录/付费墙
- 新内容放到首页，加快收录
- 加载快、移动端友好
- 内容要原创、跟核心词相关、定期更新
- 页面不是越多越好，跟核心词相关的页面越多越好
- 标题没有严格长度限制，更长标题甚至有助于排名，但不一定有助于 CTR

### 4.7 变现

| 路径 | 他的口径 |
|---|---|
| Adsense | 入门路径；日 UV 过 500–1000 再申请 |
| 用户付费 | AI 工具站上，能靠广告赚 10 刀，付费往往能赚 30–50 刀 |
| 混合 | 他自己两个都做 |
| 卖站 | 及时卖掉也是策略 |

练手顺序：先做小游戏站（容易起量、变现低）→ 再做 AI 工具站（同流量变现高）。  
第一个站进前 10 → 第二个站日点 100 → 第三个站日点 1000。

## 5. GEO 和自动化

- 会做 SEO，才能做好 GEO，两者互通
- 新站早期，ChatGPT 等 AI 搜索来的量可以接近甚至暂时超过谷歌
- 内容站容易被 AI 替代；工具站、游戏站、电商站、影视站替代不了，反而会接到 AI 导流
- 社群里已有人用 Agent 自己挖词、注册域名、上站、提交外链
- [seo.web.cafe](https://seo.web.cafe/) 把挖词、KD、KGR、SERP、On-Page、外链估价、Adsense 预检做成工具

## 6. 第一个站的最小清单

1. 用谷歌下拉 + Ads + Trends 收一批词，删掉不相关和同义重复。
2. 选一个 KD < 10、KGR < 0.25、你能做功能的词。
3. 用这个词注册不带减号的 `.com`。
4. 先写词表和 URL 清单，再写代码。首页放核心工具，再做 3–5 个相关内页。
5. 每个页独立 Title / Description / H1，服务端渲染，真链接，能不登录就试用。
6. 上线，提交 GSC，发几条能被谷歌爬到的外链。
7. 每天盯 GSC 和目标词排名；外链按周持续加。
8. 日 UV 过 500 再接 Adsense；工具站同时接支付。
9. 这个词跑通后，再挖相邻意图，加页面、加语言。

## 7. 边界

**擅长**

- 谷歌上还没被做透的新需求 / 长尾工具需求
- 程序员能一周内做出来的小站
- AI 把老需求变成新需求的窗口期

**不擅长**

- 老板不信 SEO 的公司站
- 高权威内容赛道靠「四个页面 + 买外链」硬刚
- 纯内容站，长期会被 AI 摘要吃掉
- 把 DR、Similarweb 榜单当目标

**需要滤镜**

- 公开战报是筛选过的
- 「新词 20 天几十万 UV」多出现在小游戏、社交爆款
- 外链部分他已经走到「买 + 自动发」，和 Google 指南冲突，长期有处罚风险
- 社群是成交漏斗：教程免费、陪跑收费
